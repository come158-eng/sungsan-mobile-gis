# 성산 모바일 GIS 제품 기준

## 제품 정의

성산 모바일 GIS는 QGIS 프로젝트를 휴대폰에서 열고 조사·편집한 뒤 다시 PC로
내보내는 성산의 독립 현장 GIS 앱이다. QField 오픈소스는 QGIS 프로젝트·렌더링·
편집 호환 엔진으로만 사용한다. 사용자가 보는 제품 이름, 첫 화면, 주요 메뉴와
현장 작업 흐름은 성산 전용이어야 한다.

## 사용자에게 보여야 하는 흐름

1. `현장 프로젝트 가져오기`
2. 최근 프로젝트 또는 가져온 프로젝트 열기
3. 지도에서 `현재 위치`, `레이어`, `현장조사`, `저장`, `결과 내보내기` 사용
4. 현장조사에서 QGIS가 지정한 편집 레이어와 입력 양식으로 점·선·면 및 속성·사진 저장
5. 자동 저장 상태와 마지막 저장 시각 확인
6. 조사 완료 후 프로젝트 폴더 또는 압축 파일로 내보내기

## 화면 기준

- 앱 이름과 일반 화면에 `Sungsan Mobile GIS` 또는 `성산 모바일 GIS` 표시
- 성산 로고와 주색 `#194793` 사용
- 첫 화면에서 QFieldCloud, 플러그인 스토어, 후원·평가 요청을 노출하지 않음
- 현장 지도 화면의 핵심 작업은 큰 한국어 버튼으로 한 번에 접근
- 휴대폰 시스템 언어와 관계없이 QML 시작 전 Android 네이티브 대화상자도
  한국어 성산 문구를 표시하며, 사용자에게 QField 제품 문구를 노출하지 않음
- 키보드 단축키를 전제로 하지 않음
- 내부 구현 클래스명과 `org.qfield` 모듈명은 호환성 때문에 유지할 수 있으나 사용자 화면에는 노출하지 않음
- 원저작권과 GPL 고지는 `오픈소스 정보` 화면에서 보존

## 저장 기준

- 객체 입력 양식의 저장은 기존 검증된 편집 엔진을 사용
- `지금 저장`은 현재 프로젝트 상태를 실제 파일에 기록한 경우에만 성공 표시
- 자동 저장은 프로젝트가 열려 있고 도형 입력·양식 저장 중이 아닐 때만 실행
- 저장 실패를 성공처럼 표시하지 않음

## 배경지도 기준

- 사용자가 VWorld 기능을 명시적으로 선택했고 프로젝트에 같은 영상이 없을 때만 온라인 레이어를 가장 아래에 추가
- 공식 WMTS의 `{z}/{y}/{x}.jpeg`, 줌 6~19 사용
- 출처 `국토교통부 브이월드(VWorld)` 표시
- 통신이 없을 때 온라인 영상을 오프라인 지도라고 안내하지 않음

## 독립성 기준

- Android 패키지 `kr.co.sungsan.mobilegis`
- 딥링크 `sungsanmobilegis://`
- 데이터 폴더 `SungsanMobileGIS/`
- 공식 QField의 패키지·설정·파일을 덮어쓰지 않음
- 공식 QField와 같은 기기에 설치할 수 있도록 provider, service, taskAffinity, JNI 식별자를 분리
- `.git`이 없는 대응 소스 ZIP 빌드도 오픈소스 정보에서 감사한 upstream 기준
  커밋을 정확한 링크로 표시

## 출시 판정

소스 정적검사만으로 APK 완료를 선언하지 않는다. 정식 현장 APK는 전체 Android
컴파일, 실제 arm64 기기 설치, 공식 QField 동시 설치, GPS·카메라·파일 권한,
QGIS 프로젝트 왕복과 VWorld 연결을 실제로 통과해야 한다.
