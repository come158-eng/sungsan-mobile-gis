성산 모바일 GIS beta3 시작화면 수정파일

이 압축파일 안에는 필요한 폴더 구조가 이미 들어 있습니다.

1. GitHub Desktop에서 Show in Explorer를 누릅니다.
2. 내려받은 ZIP을 압축 해제합니다.
3. 압축을 푼 폴더 안의 다음 3개 항목을 선택합니다.
   - MODIFICATIONS.md
   - scripts 폴더
   - src 폴더
4. 선택한 3개 항목을 sungsan-mobile-gis 폴더 안에 복사합니다.
5. 같은 이름의 파일을 바꿀지 물으면 "대상 폴더의 파일 덮어쓰기"를 누릅니다.
6. GitHub Desktop에 변경 파일 6개가 나타나면 Summary에 아래 문구를 입력합니다.
   Fix Fold7 startup crash for beta3
7. Commit to main을 누른 다음 Push origin을 누릅니다.
8. GitHub 웹사이트의 Actions에서
   Sungsan Android APK (manual and isolated) > Run workflow를 한 번만 실행합니다.

주의
- 기존 beta2 APK는 같은 결과가 나므로 다시 설치하지 않습니다.
- 새 결과 파일명에 beta3와 10000003이 반영됩니다.
- 이 수정은 시작 시 SVG와 Qt Quick 그래픽 효과를 제거한 안전 시작 수정입니다.
- 실제 폴드7 실행 결과는 새 APK 설치 후 확인해야 합니다.
