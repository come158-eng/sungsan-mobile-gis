성산 모바일 GIS 1.2.1 배포 안내

일반 사용자는 GitHub Actions 결과에서 다음 파일만 설치합니다.

  Sungsan-Mobile-GIS-v1.2.1-arm64-SIGNED-RELEASE.apk

- UNSIGNED 파일은 서명 입력용이므로 설치하지 않습니다.
- DEBUG-KEY-TEST-ONLY 파일은 내부 시험용이므로 현장 배포에 사용하지 않습니다.
- Android versionCode는 10201000입니다.
- 기존 앱과 같은 성산 배포 인증서로 서명된 APK는 데이터 유지 상태로 업데이트할 수 있습니다.

현장 전 필수 확인

1. PC QGIS 플러그인에서 프로젝트와 LandStar 작업 좌표계가 같은지 확인합니다.
2. 현장용 ZIP을 만들 때 좌표계 확인란을 직접 체크합니다.
3. LandStar에서는 RTK FIX 상태와 안테나고를 확인한 뒤 측점을 저장합니다.
4. LandStar에서 TXT/CSV/PXY/KOF를 공유하고 성산 GIS를 선택하면 자동 반영됩니다.
5. 첫 측점은 알려진 기준점과 대조한 후 나머지 작업을 진행합니다.
6. 지점을 눌러 근경·원경·기타·추가 사진을 촬영하고 결과 ZIP을 내보냅니다.
